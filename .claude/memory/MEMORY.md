Run: `flutter run -d macos --dart-define=DASH_SHOT_DIR=<out> --dart-define=DASH_SHOT_VAULT=<vault>`. It saves/restores the `vault_path` pref (was clobbering the user's real vault before 2026-07-18).
- **Flutter gotchas learned the hard way**: EditableText's default strut is `forceStrutHeight: true` — pass an explicit non-forced StrutStyle or lines can't grow (needed for inline WidgetSpan images + headings). Never make an AnimationController a lazy `late final` — first touch in dispose() creates a ticker during unmount → "deactivated widget's ancestor" crash. Controller listeners doing `Overlay.of(context)` need mounted guards + removeListener in dispose. `String.lastIndexOf(x, -1)` throws.
